BD Lead Engine

A self-hosted system that finds Bangladeshi companies in a chosen industry, identifies the person who decides, stores the lead in a CRM with its evidence, alerts the team on Telegram and sends approved, scheduled emails.

Python 3.11 · FastAPIPostgreSQL 16Playwright / Chromium Google Places API (New)Gemini APIDocker Compose

Overview

Five requirements from the client, and the component that owns each one.

RequirementComponentHow it is met
Target a market and switch it laterIndustry presets + CampaignsEach campaign picks an industry from a dropdown. A preset holds the search phrases (e.g. hospital, diagnostic center) and the decision-maker titles. Both are editable in the admin panel.
Company detailsPlaces discovery + website crawlerOfficial Places API for name, address, phone, website, rating. The crawler adds emails, extra phones and social pages from the company's own site.
Decision makerExtractor (Gemini) + search fallbackAI reads the Board / Management / About pages; if nobody senior is found, public search snippets are checked. Every person carries a source link and a score.
WhatsApp / Telegram alertNotifierRun summary and a card per high-confidence lead. Telegram by default; WhatsApp through the official Cloud API when configured.
Google Sheet CRM + scheduled emailSheets mirror, Outbox, DispatcherLeads are mirrored one-way to a Sheet. Emails are drafted from a template, approved, then sent inside a set time window with a daily cap.

Architecture

Three services on one server share one database. Everything outside the dashed line is a third-party API, configured from the admin panel.

The database is also the job queue (SELECT … FOR UPDATE SKIP LOCKED), so there is no Redis or message broker to run. The Google Sheet is a copy; the database is the source of truth.

Pipeline

A campaign run is split into small jobs. Each job does one stage for one company and can be retried on its own.

run_campaignonce per run

Builds the search plan: every industry phrase × every city, e.g. diagnostic center in Chattogram, Bangladesh. Stops early with a clear note if the Places key is missing.

discoverone per phrase, chained

Calls Places Text Search, up to 3 pages of 20. Skips permanently closed places. De-duplicates by Place ID, then website domain, then name + phone. A Facebook page listed as "website" is stored as a social link, never as a domain. Page progress is saved so a retry never pays twice. Stops at the campaign's company limit.

crawl_companyper new or stale company

Plain HTTP first; headless Chromium when the page needs JavaScript. Visits only same-site pages whose link looks like leadership or contact, in English or Bangla (Board, Management, Chairman's message, পরিচালনা পর্ষদ, যোগাযোগ).

  • Obeys robots.txt, waits between requests to one site, max 8 pages.
  • Extracts emails (including info [at] site [dot] com), BD numbers normalised to +880, social links and page text.
  • Companies enriched in the last 30 days are not crawled again.
find_decision_makerper company

Gemini returns candidates as {name, title, source, evidence_quote}. If no senior person with confidence ≥ 55 comes back, two search queries run and Gemini reads the snippets. The candidate list is merged, scored, and the best person is chosen with an email address.

finalize_runwhen no jobs remain

Counts results, mirrors the run's leads to Google Sheets, sends the Telegram summary and hot-lead cards, and creates email drafts for leads that have an address.

Accuracy model

The AI may only report what the page says. Each person shown in the panel carries the reasons for their score.

Hallucination guard

  • A name that does not appear word-for-word in the fetched text is discarded.
  • An evidence quote that is not verbatim costs 30 points.
  • A search snippet that does not mention the company is rejected, so a namesake at another firm is not picked.
  • "MD" is read as Managing Director, but not in a medical degree such as MBBS, MD (Medicine).

Confidence score (0–100)

+40named on the company's own website
+25in a search result that names the company
+15title matches the campaign's titles
+10both sources agree
+10top-level title (MD, CEO, Chairman…)
−30quote not found verbatim

High ≥ 70 Medium 40–69 Low < 40

Email rules

Sending runs from a plain Gmail account, so the rules are strict by default.

Before an email exists

  • Template with variables such as {{company_name}}, {{first_name}}.
  • Optional Gemini opening line, limited to facts the system holds.
  • Drafts wait for approval. Auto-approve only for confidence ≥ 70 with a real (not guessed) address.

At send time

  • Only inside the window, default Sun–Thu 10:00–17:00 Dhaka.
  • Daily cap (default 40) and a random 60–180 s gap.
  • Checks the suppression list, do-not-contact status and a 30-day per-company cooldown.
  • Unsubscribe link and header on every email; a refused recipient is suppressed.

Reliability

SituationBehaviour
API error or timeoutRetried after 1 min, 5 min, 30 min; then marked failed with the error, and a Retry button on the run page.
API key not setThat stage is skipped with a note ("Gemini key not set"); company data is still collected.
Daily call cap reachedJobs pause until 00:05 Dhaka time; one Telegram alert.
Worker restarts mid-runInterrupted jobs return to the queue. Stages are idempotent, so nothing is duplicated or paid for twice.
Website down or blocked by robots.txtRecorded on the run; the lead keeps its Places data and can still get a decision maker through search.

Security & compliance

Security

  • API keys encrypted at rest (Fernet), masked in the panel, never logged.
  • bcrypt passwords, signed session cookie, CSRF token on every form, login throttling.
  • Panel bound to localhost by default; HTTPS through Caddy.
  • Audit log of logins and setting changes (names, not values).

Data sources

  • Google data only through the official Places API, not Maps page scraping.
  • No logged-in LinkedIn scraping: public search snippets and a link only.
  • WhatsApp only through Meta's Cloud API.
  • Business contact information only; client's legal team confirms outreach policy.

Known limits

Tested so far: 38 automated tests on SQLite and PostgreSQL, a crawl of a local website, and a click-through of the panel in a real browser. External APIs were simulated. The first live run with real keys is still to be done on the client's server.
  • Places returns at most 60 results per search phrase; more coverage comes from more phrases and cities.
  • Follow-up email sequences, reply detection and Telegram commands are planned, not built.
  • Gemini model names change often; the panel's Test button lists the models the key can use.
